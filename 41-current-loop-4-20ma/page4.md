## 这次实验要验证什么

本页用 Arduino 的 PWM、一片 LM358、一只 2N3904 和几只电阻，在 12 V 下搭一个 4–20 mA 发送器，再用电阻 $R_x$ 模拟长导线。要亲手验证五件事：

1. **恒流**：设定 4/12/20 mA，250 Ω 接收电阻上分别是约 1/3/5 V，而且 $R_x$ 从 0 换到 220 Ω，电压几乎不变（[直觉篇](page1.md)、[原理与实现篇](page2.md)「二」）。
2. **β 误差**：回路电流（250 Ω 上量）比发射极电流（100 Ω 上量）少约 1 %（[原理与实现篇](page2.md)「三」）。
3. **顺从极限**：导线电阻大到一定程度时，回路电流和 A0 读数还一致吗？谁能报警？（先回想[参数与调试篇](page3.md)「一」，在表 2 里验证。）
4. **NE43 报警电流和断线**：低故障 3.4 mA、高故障满码约 22.5 mA；拔掉 $R_x$ 模拟断线（[参数与调试篇](page3.md)「二」）。
5. **5 V 引脚陷阱**：不填实测的 5 V 值，Arduino 自己看不出电流偏了（[参数与调试篇](page3.md)「六」）。

所有核心结论都用万用表验证。

## ⚠️ 安全须知

- **只用 12 V 直流适配器**（≤ 12 V DC）。不要接市电，不要换更高电压。
- **Arduino 只用 USB 供电**，它的 5 V 引脚**不接**面包板；12 V 也**绝不**接到 Arduino 的任何引脚上。
- **Arduino 只接四根线**：D9、A0、A1、GND。A0 接发射极（经 10 kΩ），A1 接 22k/10k 分压点。**A0 绝不能接 250 Ω 的下端**：那里对地有 7–11 V。
- A0、A1 两根线**最后接**，接之前先用万用表确认它们对地 ≤ 5 V（步骤 12）；量完**先拔 12 V，再拔 USB**，断电后再接这两根线。
- 电解电容 C1 有正负极：长脚（+）接 i5，短脚（−）接 0 V 轨。插反可能鼓包。
- 正常时三极管最多约 103 mW，按手册热阻温升约 20 °C；就算 250 Ω 被短接也只有 200 mW、约 40 °C。**不要用手摸元件试温度**，觉得异常就先拔 12 V。
- 改线前先拔 12 V，再拔 USB。下面表格里只换 $R_x$ 或面包板上的短线时，拔 12 V 就够（Arduino 一侧只有 5 V）；动 Arduino 的线（D9、A0、A1、GND）时，12 V 和 USB 都要拔。每一处要改线的地方都会再提醒一次。

## 搭建步骤

1. **电源轨。** 断电。12 V 电源 + 接上方 +12 V 轨（第 1 列），− 接上方 0 V 轨。一根黑线把上方 0 V 轨第 34 列接到下方 0 V 轨第 34 列；一根橙线把上方 +12 V 轨第 35 列接到下方 +12 V 轨第 35 列。
2. **PWM 滤波。** R1 12 kΩ 插 h1–h5；R2 10 kΩ 从 j5 接下方 0 V 轨；C1 10 µF 长脚插 i5、短脚插下方 0 V 轨（第 7 列）；绿线 g5 → g14。
3. **LM358。** 缺口朝左跨在中槽上，1–4 脚在 f12–f15，8–5 脚在 e12–e15。a12 → 上方 +12 V 轨（8 脚供电）；100 nF 从 b12 接上方 0 V 轨；c13 → c14 短线（7 脚接 6 脚）；a15 → 上方 0 V 轨（5 脚接地，B 半闲置成跟随器）；j15 → 下方 0 V 轨（4 脚接地）。
4. **中途检查：先只测 PWM 滤波（12 V 不接）。** Arduino GND 接下方 0 V 轨第 25 列，D9 接 j1。插 USB，先用万用表量 Arduino 板上 5V 引脚对 GND（只是表笔碰一下，不接线）：板上 5 V 引脚常见 4.8 V 左右（论坛实测例 4.83 V），必须实测。把读数写进下面程序的 `V5`，再上传。串口输入 `20`，量 j14 对 0 V 轨，应约 2.0 V（ `V5` 填对时，不管 5 V 引脚是 5.00 还是 4.83 V 都是约 2.0 V）。读到 0 V 查 D9 线和 R1；读到 4 V 以上查 R2 是否接到 0 V 轨。测完拔 USB，再继续搭。
5. **A1 分压。** R3 22 kΩ 插 i12–i9；R4 10 kΩ 从 j9 接下方 0 V 轨。h9 留给 A1。
6. **基极。** $R_B$ 1 kΩ 插 h12–h17；绿线 g17 → g23。
7. **三极管。** 2N3904 平面朝自己，E、B、C 插 f22、f23、f24。
8. **反馈和采样。** 绿线 i13 → i22（运放 2 脚接发射极）； $R_S$ 100 Ω 从 j22 接下方 0 V 轨。
9. **A0 串联电阻。** 10 kΩ 插 h22–h27。j27 留给 A0。**不要**在 A0 上加下拉电阻。
10. **回路。** 250 Ω 插 i24–i29；先用一根短线代替 $R_x$ 插 h29–h33（ $R_x$ = 0）；橙线 j33 → 下方 +12 V 轨。
11. **通电前检查。** USB 和 12 V 都不接，万用表电阻挡：上方 +12 V 轨对 0 V 轨不能接近 0 Ω（那是短路）；再量下方两条轨之间，也不能接近 0 Ω。读数接近 0 就先找错，别通电。没问题后插 USB（程序在步骤 4 已经上传），最后插 12 V。
12. **接 A0、A1 之前。** 串口输入 `20`，用万用表黑表笔接 0 V 轨，量 j27（应约 2.0 V）和 h9（应约 0.9 V）。都 ≤ 5 V 后，**先拔 12 V，再拔 USB**，断电后把 j27 → A0、h9 → A1 接上；检查无误（没有插到 +12 V 轨或第 33、35 列）后先插 USB，最后插 12 V。

画图脚本会逐条检查上面每一处连接，并确认 +12 V 轨、0 V 轨、Arduino 引脚之间没有接错；接错一处图就画不出来。

## Arduino 程序

> **第一次用 Arduino？** 上传方法见 [35 程控增益与 AGC · 动手实验篇](../35-pga-agc/page4.md)「最小必要知识：Arduino 上手」。

> ⚠️ 下面的程序**未经运行验证**：我们没有在真实的 Arduino 上跑过它。它的换算公式和 `code/41_sim.py` 里的模型一致（码、A0、A1 的换算都在那里算过）。上传后如果行为和描述不同，先看串口打印的 code 和读数。

程序做四件事：① 从串口读目标电流，按实测 `V5` 算出 PWM 码；② A0 读发射极电压，算 $I_E$ ；③ A1 读运放输出，算余量 $H = V_O - V_E$ ，超过 1.3 V 报警；④ 按 NE43 给 $I_E$ 分区。

串口监视器设成 9600 波特、“换行”结尾。可以输入：`4`、`12`、`20`（或任意 0–22.7 的数字，单位 mA）；`L` = 低故障 3.4 mA；`H` = 高故障（满码 255）；`T` = 从 4 mA 跳到 20 mA，约每 20 ms 打印一次，看建立时间（16 次 `analogRead` 加上 9600 波特打印一行都要时间，实际间隔略长于 20 ms，以打印出的 ms 数为准）；`0` = 关。输入了不是数字的内容（比如打错成 `x`）， `toFloat()` 会得到 0，等于关掉输出。

```cpp
// 41 4–20 mA 发送器：PWM 设定电流，A0 读发射极（I_E），A1 读运放输出（算余量 H）
const float V5     = 5.00;          // ← 用万用表量 5V 引脚对 GND，填实测值！
const float R_S    = 100.0;         // 采样电阻 Ω
const float K_SET  = 10.0 / 22.0;   // PWM 分压 R2/(R1+R2) = 10k/(12k+10k)
const float K_A1   = 10.0 / 32.0;   // A1 分压 10k/(22k+10k)
const float H_ALARM = 1.3;          // 余量报警门限（V）
const int   PIN_SET = 9;            // D9：约 490 Hz PWM

int code = 0;

int codeFor(float mA) {             // 目标电流 → PWM 码
  float c = mA / 1000.0 * R_S / (V5 * K_SET) * 255.0;
  if (c < 0) c = 0;
  if (c > 255) c = 255;
  return (int)(c + 0.5);
}

float readAvg(int pin) { long s = 0; for (int i = 0; i < 16; i++) s += analogRead(pin); return s / 16.0; }

float readIE() { return readAvg(A0) * V5 / 1024.0 / R_S * 1000.0; }   // mA

const char* ne43(float mA) {
  if (mA <= 3.6)  return "FAULT-LOW";
  if (mA >= 21.0) return "FAULT-HIGH";
  if (mA >= 3.8 && mA <= 20.5) return "MEASURE";
  return "TRANSITION";
}

void setCode(int c) { code = c; analogWrite(PIN_SET, code); Serial.print("code = "); Serial.println(code); }

void stepTest() {                   // 4 mA → 20 mA 阶跃，打印 1 s
  setCode(codeFor(4.0)); delay(1000);
  unsigned long t0 = millis();
  setCode(codeFor(20.0));
  while (millis() - t0 < 1000) {
    Serial.print(millis() - t0); Serial.print(" ms  I_E = "); Serial.println(readIE(), 2);
    delay(20);
  }
}

void setup() {
  pinMode(PIN_SET, OUTPUT); analogWrite(PIN_SET, 0);
  Serial.begin(9600);
  Serial.println("41 current loop: type 4 / 12 / 20 (mA), L, H, T, 0");
}

void loop() {
  if (Serial.available()) {
    String s = Serial.readStringUntil('\n'); s.trim();
    if (s == "L" || s == "l")      setCode(codeFor(3.4));
    else if (s == "H" || s == "h") setCode(255);
    else if (s == "T" || s == "t") stepTest();
    else if (s.length() > 0) {
      float mA = s.toFloat();
      if (mA >= 0 && mA <= 22.7) setCode(codeFor(mA));
      else Serial.println("range 0 - 22.7 mA");
    }
    delay(500);                     // RC 建立约 0.25 s，等 0.5 s 再读
  }
  static unsigned long tLast = 0;
  if (millis() - tLast >= 1000) {
    tLast = millis();
    float iE = readIE();
    float vE = iE / 1000.0 * R_S;
    float vO = readAvg(A1) * V5 / 1024.0 / K_A1;
    float h  = vO - vE;
    Serial.print("code="); Serial.print(code);
    Serial.print("  I_E="); Serial.print(iE, 2); Serial.print(" mA  ");
    Serial.print(ne43(iE));
    Serial.print("  H="); Serial.print(h, 2); Serial.print(" V");
    if (code > 0 && h > H_ALARM) Serial.print("  ALARM: loop open or saturated!");
    Serial.println();
  }
}
```

几点说明：

- `codeFor()` 就是 [原理与实现篇](page2.md)「二」的公式反过来算。`V5` = 5.00 时，4/12/20 mA 得到码 45/135/224；`V5` = 4.83 时是 46/…/232。
- 程序报的 `I_E` 是**发射极电流**，不是回路电流。回路电流以万用表量 250 Ω 为准。
- `ALARM` 只看余量 $H$ ：能抓住断线和 470 Ω 这类明显饱和，抓不住“差一点点”（[参数与调试篇](page3.md)「一」）。

## 没有示波器怎么办

- **建立时间**：串口输入 `T`，程序在阶跃后大约每 20 ms 打印一次 $I_E$ （实际间隔略长于 20 ms，以打印出的 ms 数为准，见上面「Arduino 程序」一节的说明）。找出 $I_E$ 到约 19.8 mA（终值的 99 %）的时刻，应约 240–250 ms（[参数与调试篇](page3.md)「三」，SPICE 0.238 s）。
- **纹波**：20 mA 时回路纹波约 89 µApp，在 250 Ω 上是 22.3 mVpp。万用表交流 mV 挡如果有，读数大约是几 mV（按三角波估算有效值约 6.4 mV；各种表对 490 Hz 非正弦波的响应不同，只看量级）。直流挡会把它平均掉，读数不受影响。
- **振荡**：万用表直流挡读数稳定、最后一位不乱跳，就说明没有明显振荡。如果乱跳，按 [参数与调试篇](page3.md)「五」检查。

## 用 Python 核对你的读数

把你量到的元件实际值（250 Ω、100 Ω、5 V 引脚、12 V 电源）和读数填进下面的变量。代码用你的元件值算出每一行**应该读到**的 250 Ω 电压和 $V_E$ ，再和你的读数比，偏差超过 10 % 就打印提示。现在 `rows` 里填的是 β = 100 的模型值，当示例。

```python
import sys, pathlib
sys.path.insert(0, str(pathlib.Path("code/figs").resolve()))  # 在仓库根目录运行
# 41 动手实验：用你自己的元件值算出“应读到”，再和读数比较
V5_measured  = 5.00     # Arduino 5V 引脚实测（V）
V12_measured = 12.0     # 12 V 适配器带载实测（V）
R_L_measured = 250.0    # 接收电阻实测（Ω）：249 Ω，或 100 Ω + 150 Ω 串联
R_S_measured = 100.0    # 采样电阻实测（Ω）
BETA = 100              # 2N3904 的 β（模型值，手册 100–300）
K = 10 / 22             # PWM 分压 R2/(R1+R2)
V_CE_MIN = 0.3          # 三极管至少要留的电压（V）

# 每行：(输入, 码, 你量到的 250 Ω 两端电压 V, 你量到的 ② 发射极电压 V)
# 码填串口打印的 code=，不要照抄默认值
rows = [("4", 45, 0.993, 0.4011), ("12", 135, 2.978, 1.2032), ("20", 224, 4.942, 1.9964),
        ("L", 38, 0.838, 0.3387), ("H", 255, 5.626, 2.2727)]

def ne43(i):
    if i <= 3.6: return "故障（低）"
    if i >= 21.0: return "故障（高）"
    return "测量值" if 3.8 <= i <= 20.5 else "过渡带"

def check(name, what, meas, calc):
    dev = (meas - calc) / calc
    flag = ""
    if abs(dev) > 0.10:
        flag = "  ← 偏差超过 10 %，先检查接线和表笔位置"
    print(f"{name:>3} {what}: 实测 {meas:.3f} V，计算 {calc:.3f} V，偏差 {dev:+.1%}{flag}")

for name, code, v_rl, v_e in rows:
    v_e_calc = V5_measured * code / 255 * K                       # 运放把 V_E 钉在 V_SET
    i_e_calc = v_e_calc / R_S_measured
    i_loop_calc = i_e_calc * BETA / (BETA + 1)
    i_lin_max = (V12_measured - V_CE_MIN) / (R_L_measured + R_S_measured * (BETA + 1) / BETA)
    i_loop_calc = min(i_loop_calc, i_lin_max)                     # R_x = 0 时的顺从上限
    check(name, "② V_E      ", v_e, v_e_calc)
    check(name, "250 Ω 两端", v_rl, i_loop_calc * R_L_measured)
    print(f"    回路电流 {v_rl / R_L_measured * 1e3:.2f} mA（{ne43(v_rl / R_L_measured * 1e3)}）")

i20 = 0.020
rx_max = (V12_measured - i20 * (R_L_measured + R_S_measured) - V_CE_MIN) / i20
print(f"你的电源 {V12_measured:.2f} V：20 mA 时 R_x 最多 {rx_max:.0f} Ω（220 Ω 这一行要 ≥ 220）")
for v5 in (5.00, 4.83):
    code20 = round(20e-3 * R_S_measured / (v5 * K) * 255)
    print(f"5V 引脚 {v5:.2f} V：20 mA 要码 {code20}；若程序仍按 5.00 V 用码 224，实际 I_E = {v5 * 224 / 255 * K / R_S_measured * 1e3:.2f} mA")
```

看输出时注意：

- 每一行的偏差应在几 % 以内。250 Ω 那一行比计算值略低 0.3–1.6 % 是 β 不同（β 60–300）造成的，正常；超过 10 % 代码会提示，先查接线和表笔位置。
- 5 V 引脚 4.83 V 时，码 224 只给 19.29 mA。你的 A0 读数**不会**告诉你这一点。

### 思考题

1. $R_x$ = 470 Ω、设定 20 mA 时，回路电流只有 13.84 mA，A0 为什么还是 20 mA？少掉的电流走了哪条路？

<details><summary>参考答案</summary>

三极管饱和，集电极拉不动更多电流；运放为了让 $V_E$ 等于 $V_{SET}$ ，拼命加大基极电流。基极电流也从发射极流出、流过 $R_S$ ，于是 $I_E$ 仍然是 20 mA，其中约 6.2 mA 是从运放经 R_B、基极过来的（模型 6.18 mA），不经过 250 Ω。

</details>

2. 如果把 2N3904 换成 2N7000，470 Ω 时 A0 会读到多少？为什么？

<details><summary>参考答案</summary>

SPICE 是 14.59 mA，和回路电流一样。MOS 管栅极不取电流，源极电流就等于漏极电流，所以 A0 看到的就是真实回路电流，电流掉了能直接看出来。

</details>

3. （只算不做）如果回路电源是 24 V，20 mA 时 $R_x$ 最多能到多少？

<details><summary>参考答案</summary>

(24 − 0.02 × 350 − 0.3) / 0.02 = 835 Ω。本节实验规定只用 ≤ 12 V，所以这一问只算不做。

</details>

4. 为什么不在 A0 上加 100 kΩ 下拉？加了会怎样？

<details><summary>参考答案</summary>

A0 经 10 kΩ + 100 Ω 接地，本来不会悬空。加 100 kΩ 下拉会和 10 kΩ 分压，A0 只看到 100 ÷ (10 + 100) = 0.909 倍（ $R_S$ 并在 $V_E$ 和地之间，不在这一串里），20 mA 显示 18.18 mA，偏低 9.1 %。

</details>

5. 5V 引脚实测 4.83 V，但程序里 `V5` 还写 5.00，输入 `20`。万用表在 250 Ω 两端会读到多少？串口显示多少？

<details><summary>参考答案</summary>

码仍是 224，实际 $I_E$ = 19.29 mA，回路电流约 19.29 × 100/101 = 19.10 mA（β = 100），250 Ω 两端约 4.77–4.78 V。串口按 5.00 V 换算显示约 19.92 mA，看起来几乎正常。这就是比例式陷阱。

</details>

6. 断线时，为什么设定 4 mA 的 $I_E$ 还是 4 mA，设定 20 mA 却只有约 8.9 mA？

<details><summary>参考答案</summary>

断线后电流只能从基极走。4 mA 时运放输出约 5.1 V 就够了；20 mA 需要的基极电流太大，运放输出顶到上限约 10.53 V，再减去 $V_{BE}$ 和发射极电压，经 R_B 1 kΩ 只能流过约 8.9 mA。

</details>

## 小结

- 设定 4/12/20 mA，250 Ω 上约 1/3/5 V； $R_x$ 在 0–220 Ω 间换，读数不变。这就是电流环抗导线电阻（图 41-p4-1、图 41-p4-2）。
- 回路电流比发射极电流少约 1 %（β 误差）。
- $R_x$ = 470 Ω 时回路电流掉到 13.84 mA，A0 仍报 20 mA；断线时 A0 报 4 或 8.9 mA；只有余量 $H$ 报警。
- 码 38 和 255 分别演示 NE43 的低、高故障电流。
- 5 V 引脚的偏差 Arduino 自己看不出，必须实测写进 `V5`。
- 每次改线都先拔 12 V；断线要把 $R_x$ 整只拔下，不让带电的脚悬着。

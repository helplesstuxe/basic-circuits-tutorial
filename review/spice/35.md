# 35 程控增益与 AGC：SPICE 复核报告

- **工具**：ngspice 44.2，batch 模式，`spice/35/.spiceinit` 设为 psa。
- **运行**：在仓库根目录执行 `python spice/35/run.py`，退出码 0，已实际运行，共 52 项（2026-10-27 修订后重跑）。
- **电压范围**：放大器全部由 5 V 单电源供电（Arduino 的 5 V 脚）；峰值检波原理仿真用 ±5 V，只在 page2 讲原理用，不进实验。

## 网表

| 网表 | 内容 |
|---|---|
| `dc_g0.cir` … `dc_g5.cir` | 六个档位 X0…X5（R_g = 100k / 24k / 11k / 5.1k / 2k / 1k，R_f = 100k），每档四套：理想开关、R_on = 125 Ω、R_on = 470 Ω、R_on = 1050 Ω（VDD 5 V 手册最大值，最坏情况）；输入 1.0 / 0.4 / 0.2 / 0.1 / 0.05 / 0.03 V（与 page4 测量表一致） |
| `dc_kelvin.cir` | 抽头接法：梯形电阻 51k/30k/10k/5.1k/3k/1k/1k，470 Ω 开关串在反相端，另一套同样的梯形电阻配 1050 Ω 开关；另含输入 0 V 时 G≈69 档的输出 |
| `clip.cir` | G≈2 档输入 0→2.5 V 扫描，求 LM358 在 5 V 下的输出上限 |
| `ac.cir` | AC 扫描：G = 101（理想开关）、G≈69（串 470 Ω）、G≈2 |
| `t_peak.cir` | 单二极管检波（1N4148 + 1 µF + 100k）与精密峰值检波（LM358，二极管在环内）；1 kHz 正弦，60 ms 时 1.0 V → 0.5 V |

## 假设

1. 导通的通道用一只电阻（R_on）代替，断开的通道看成开路；不仿真开关的电荷注入和切换瞬间。
2. Arduino 的 ADC 输入看成开路（实验里经 1 kΩ 接 A0，ADC 输入电流可忽略）。
3. LM358 模型自带约 1.9 mV 失调。手册最大 ±7 mV，所以凡是“含失调”的读数，真实芯片会在一个范围内变。

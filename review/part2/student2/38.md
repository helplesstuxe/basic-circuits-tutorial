## 7. 举一反三：改成 5 Hz 励磁，同时适配 50 Hz 和 60 Hz 电网

脚本：`/tmp/bct-run/38/var/variant.py`。

- 我的思路：要让工频干扰在一个励磁周期内平均为 0，工频必须是励磁频率的**偶数倍**。6.25 Hz 时，50 Hz 是 8 倍，可 60 Hz 是 9.6 倍，不行。5 Hz 时，50 Hz 是第 10 倍、60 Hz 是第 12 倍，都是偶数。
- Timer1：/256 分频，TOP = 6249，每计数 0.0288°。45° = 1562.5 个计数，不是整数，只能取 1562 或 1563。
- 仿真读数（无干扰 / 加 50 Hz / 加 60 Hz）：
  - 6.25 Hz：50.90 / 50.82 / 50.82 mV
  - 5 Hz：50.88 / 50.90 / 50.87 mV
- 代价：AC 耦合造成的跌落从 7.7% 升到 9.5%；CF 上的纹波约 10 / 8.7 mV 峰峰值。BLANK 要改成 50 ms（半周期变成 100 ms）。
- 结论：5 Hz 一套参数能同时服务 50 Hz 和 60 Hz 电网，代价是多一点跌落。这说明我真的理解了「偶数倍才能抵消」这条规律。

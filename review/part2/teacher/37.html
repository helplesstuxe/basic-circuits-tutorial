180° 方法核算（用页面参数 L = 0.20 m、c = 343.24 m/s、v = 3 m/s）

设每次读数为 t = L/(c ± v) + b。b 包含探头、放大、比较器、整周期偏移（约 125 µs），以及第 8 步拟合截距吸收掉的那部分。

  • 方向 A（发射探头靠风扇，声音顺风）：dA = 开 − 关 = L/(c+v) − L/c = 577.634 − 582.683 = −5.049 µs
  • 方向 B（整根木条转 180°，接收探头靠风扇，声音逆风）：dB = L/(c−v) − L/c = 587.821 − 582.683 = +5.138 µs

推导：

  • 每一组「开减关」里，b 都会消掉。木条整体转动不改变两探头的间距 L，也不改变谁发谁收，所以 b 在两个方向上本来就相同。即使 b 不同（比如风扇和墙面反射不一样），也已在各自的组内消掉。
  • dB − dA = L/(c−v) − L/(c+v) = 2Lv/(c² − v²) = 10.186 µs，恰好等于 Δt。由此反求 v = Δt·c²/(2L) = 3.000 m/s。
  • 1 mm 的放置误差只通过 L 进入 dA、dB，是 0.5 % 的比例误差，不会像对调探头那样带来 2.913 µs 的绝对误差。
  • 开的读数减去前后两次关的平均，可以消掉线性的温度漂移。

结论：数学上严格抵消探头和电路的偏移，风向符号正确（dA < 0 < dB），与 L295 的 assert dA < 0 < dB 一致。

页面 L216 写「按本节模型 −5.12 / +5.13 µs，相减 10.25 µs」，这是 8 MHz 采样模型的值。模型的回波延迟按 125 ns 取整，所以两边都是 ±5.125 µs；理论值是 −5.05 / +5.14 µs，|dB| 比 |dA| 大 2Lv²/(c(c²−v²)) ≈ 0.09 µs。这不影响任何结论（Python 段算出 3.01 m/s），只在新建议-04 里提一句。

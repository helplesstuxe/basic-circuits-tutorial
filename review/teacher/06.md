# 06 MOS 管开关：资深教师审读

审读对象：`06-mosfet-switch/page1–3.md` 及其图。

## 总评

"栅极 = 带小水桶的阀门"这个类比，把"稳态不耗电、开关要搬电荷"的道理讲得很到位，后面的米勒平台、开关损耗随频率增加都由它自然引出。page2 按"三段开通 → 损耗公式 → 逐纳秒仿真 → 损耗 vs 频率"推进，例题、扫描图和练习的数字互相印证。下列数值已复核，全部正确：
- 12.4/11.2 μJ；
- 4.8 kHz 交点；
- 0.580 W 与 2.450 W；
- 06-p3-1 的 0.047/0.468/4.678 W；
- 06-p3-2 的 0.20–0.43 W；
- 练习 3 的 297 °C。

IRLZ44N、AO3400A、IRF540N 的引用参数与手册相符。主要问题是"体二极管"未定义就用于排查步骤，另有两处表述错误。

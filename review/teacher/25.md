# 25 H 桥电机驱动 · 资深教师审读

## 总评

全节质量高。

- **page1**：用"四道闸门的 H 形水渠"引出 H 桥，"斜着成对打开"的口诀好记；刹车和直通两种状态单独讲，并配了一张"正转—滑行—正转—刹车—反转"的仿真时序图，读者能直接看到"刹车比滑行停得快得多"。
- **page2**：体二极管在 L11 先定义再使用，是全书少有的做法（21、09、26 都没有这样处理），可以作为范例。三段推导都配了"中文意思"。例 3 指出 DRV8871 倒车时"IN1 高电平占空比是 70%，不是 30%"，正好戳中新手的典型误区。
- **page3**：用两次扫描（死区、PWM 频率）把"死区不短于过渡时间"和"刚好避开可听范围"两条规则讲成可以验证的结论。练习 4 的迁移题（8 A 车窗电机）设计得好，能逼读者列出芯片替他做了哪些事。

**数值复核**（全部无误）：

- 转速与电流：稳态 563 rad/s = 5377 rpm（I = bω/K = 0.28 A）。滑行 0.3 s 后 5377·e^{-0.3} ≈ 3983 rpm，刹车 0.2 s 后 ≈ 183 rpm。刹车时间常数 τ = 1e-5 / (0.0004/2.516 + 1e-5) = 59 ms，2.3τ = 136 ms。纹波 0.15 A、0.1125 A。
- page2 例题：2686 rpm、4030 rpm、IN1 70%、−3.6 V。
- page3：I_TRIP 表 4.27 / 3.20 / 2.67 / 2.00 / 1.49 / 1.00 A；1.84–2.16 A。直通功率 3.66 / 2.08 / 0.93 / 0.24 W。L/R = 0.5 ms。纹波随频率按 1/f 变化。练习 42.7 kΩ（1.37–1.60 A）、4 W、30 kHz。
- 滑行时电流约 11 µs 降到 0：用 0.28 A × 1 mH / ≈25 V ≈ 11 µs 复核成立。

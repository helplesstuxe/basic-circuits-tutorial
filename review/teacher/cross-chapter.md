## 三、重复或矛盾的讲法

### 3.1 有限开环增益

- **现状**：闭环增益公式 A_v = A/(1+Aβ) 这类有限开环增益的修正，在 P3、01、03 中**各推导了一遍**，符号也不完全一致。
- **建议**：只在 P3 page2 推导一次，作为"为什么虚短只是近似"的依据；01 和 03 改成"代入 P3 page2 的公式"，用一个数值例子回扣。这样可以减轻重复的认知负荷，也能起到提取练习的作用。

### 3.2 虚短的措辞

- **现状**：P3 写明"虚短只在负反馈、输出未饱和时成立"，但 02、03、04、13、07 引用虚短时**省略了"未饱和"这一条件**。13 的微分器恰好容易饱和，是最需要这个条件的地方。
- **建议（必改级别的提醒放在 P3.md #1）**：各节第一次使用虚短时统一写成"负反馈且输出未饱和时，虚短成立（见 P3 page1）"。13 在讲输出被尖峰顶到电源轨时，应明确写"此时虚短失效"。

## 四、导航顺序

现行顺序（00-design §5.3）：

> P1 → P3 → P2 → 17 → 01 → 21 → 22 → 02 → 05 → 14 → 18 → 03 → 06 → 12 → 19 → 04 → 10 → 13 → 07 → 15 → 08 → 11 → 23 → 16 → 09 → 25 → 20 → 24 → 26

这个顺序满足依赖关系，但它是按"4 名作者并行写作"的调度排出来的，**对读者来说主题交错**，例如运放 → 继电器 → MOS → 运放 → 互锁 → 跟随器 → 整流 → 星三角……读者每读一两节就要换一次脑子里的模型，提取练习的线索也断了。另外，P3 先于 P2，但 P3 已经提到三极管。

**建议**：README 增加一条"按主题分组"的推荐阅读顺序。下面这条顺序已逐条核对 §5.2 的 55 条边，全部满足依赖：

> **基础**：P1 → P2 → P3
> **运放主线**：01 → 02 → 03 → 04 → 05 → 12 → 13 → 14 → 15 → 16
> **电源主线**：06 → 10 → 07 → 08 → 09
> **开关与接口**：21 → 22 → 23 → 24 → 25 → 26
> **继电-接触器控制**（市电）：17 → 18 → 19 → 20 → 11

这样排的好处：

- P2 在 P3 之前，三极管不再"先用后讲"。
- 体二极管（21）、续流（22）、光耦（23）在使用它们的 09 之后、24 和 25 之前集中讲完。顺带一提，这样排 09 仍在 23 之前，09 page2 L178 最好写成"光耦见 23"。
- 市电节点 17–20 和 11 集中在最后，读者到这里已经熟悉继电器（22）和比较器（14），安全提示也可以集中强化。
- 11 放到 17–19 之后，"三相"已经有了定义。

代价是要改各页顶部的"上一页 / 下一页"链接和 26 page3 的"最后一页"说法。如果作者不想改现有链接，至少在 README 里把分组顺序作为"推荐阅读顺序"列出来，并在 P3 里给三极管加一个指向 P2 的链接。

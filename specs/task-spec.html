任务说明：20 种常见标准电路教案

用户原话（2026-10-22）

「根据skills，创建新仓库，完成20个电路的教学md文档和图片。我只有高中生第电路水平」 附图：source-20-circuits.jpg（标题「20种常见标准电路」，一共 24 个小格，有几个编号重复）。

定位

面向只有高中物理电路基础的学习者，用浅显易懂但不失严谨的方式，深入讲解 20 种常见标准电路。

交付物

新 GitHub 仓库，内容为 Markdown 教案加 Python 生成的图片。本轮不做 HTML。

学习者画像

  • 会的：欧姆定律、串联和并联、电功率、简单的电源和开关电路；可能听说过电容。会一点点 Python，或者能照着运行脚本。
  • 不会的：电容充放电的定量规律、电感、交流的相位、二极管和三极管、MOSFET、运放、反馈、复数和频率响应、微积分、继电器和接触器控制电路。
  • 规则：凡是用到「不会的」知识，必须先补最小必要知识。积分和微分要从「面积」「斜率」的直觉讲起，不能默认读者已经学过微积分。

硬性交付标准（每个知识点）

  • 3 个 md 页面，每页正文不少于 500 汉字，不含代码和公式。
    • page1「直觉篇」：痛点引入、生活类比、示意图。
    • page2「原理与实现篇」：推导，加一段带逐行注释的最小可运行 Python 仿真代码，输出 png。
    • page3「参数与调试篇」：每个元件参数的物理含义、取值范围，以及改变参数后波形或效果怎么变；常见故障排查表（现象 → 原因 → 怎么查 → 怎么改）；练习题，答案放在
      里。
  • 符号全书统一，首次出现必须解释：
    • 输入电压 V_i（或 V_in）、输出电压 V_o，电源 V_CC 和 V_EE。
    • 电阻 R、电容 C、电感 L，电流 I，时间 t，频率 f。
  • 代码统一用 Python 3 + NumPy + matplotlib，必要时可以加 SciPy；必须真的跑通，否则标「未经运行验证」。
  • 图：
    • 电路图用 Python 的 schemdraw 绘制，波形和曲线用 matplotlib，全部是 PNG。禁止 ASCII 图和直接渲染的 Mermaid。
    • 图号写成「图 NN-pX-k」；每张图都要有引导句、图注和图后讲解。
    • 答案图要放在揭晓之后。
  • 链接和引文必须真实可访问，否则标「[待核实]」，禁止编造。
  • md 里的公式必须能在 github.com 上正常渲染（遵守技能第 6 节的规则）。
  • 教学闭环：痛点先行，直觉先于严谨，渐隐式例题（完整示例 → 关键步骤留空 → 变体迁移）。
  • 安全提醒：涉及市电（220V/380V）的内容（整流、开关电源、自锁、互锁、星三角、双控开关）必须写明安全警示，仿真和实验只建议在低压下做。

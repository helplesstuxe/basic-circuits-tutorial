## 二、RC 网络只"偏爱"一个频率

**意思**：低频时串联电容像断开，信号过不去；高频时并联电容像导线，把信号短路到地。只有在中间某个频率 $f_0$ ，网络送到同相端的信号最大，而且和输出**步调一致**（不超前也不落后），这时正反馈才是"顺着推"。

$$f_0 = \frac{1}{2\pi R C}$$

**代数**： $f_0 = 1/(2\pi \times 10000 \times 10 \times 10^{-9}) \approx 1592$ Hz。

网络的输出（同相端电压 $V_+$ ）与输入（运放输出 $V_o$ ）的幅度之比是

$$\frac{V_+}{V_o} = \frac{1}{\sqrt{9 + (f/f_0 - f_0/f)^2}}$$

这个式子要用复数推，超出高中范围，这里直接用结论（TI 应用笔记 SLOA060 同样给出 $f_0$ 处反馈系数为 1/3）。不过 $f_0$ 这一点可以自己验证。在 $f_0 = 1/(2\pi RC)$ 处容抗正好等于 $R$ 。串联支路：电阻和电容上的电压一样大、错开四分之一周期，按 [20 有源滤波 · 原理与实现篇](../20-active-filter/page2.md) 的直角三角形，总"阻碍"是 $\sqrt{2}R$ 。并联支路：流过电阻和电容的电流一样大、也错开四分之一周期，总电流是单支的 $\sqrt{2}$ 倍，所以总"阻碍"是 $R/\sqrt{2}$ 。两者之比 2:1，而且两条支路的"错开程度"正好相同，可以直接按比例分压：并联支路分到 1/(2 + 1) = 1/3。code/figs/24_figs.py 用复数核对过这个结果。

代数：在 $f = f_0$ 处括号为 0，比值是 1/3；在 $f_0$ 的 10 倍或十分之一处，括号约为 9.9，比值约 0.097。曲线见 图 24-p2-2。

![蓝绿色虚线是一个山峰形曲线，峰顶在 1592 赫兹，峰值 0.333](img/24_p2_2_wien_select.png)

*图 24-p2-2　文氏桥网络的选频特性*

图 24-p2-2 中，蓝绿色虚线（反馈网络）在 1592 Hz 处达到最高点 0.333，两边都下降。所以网络把输出"打折"成三分之一送回去。要让信号一圈下来不变小，放大器必须把它放大 **3 倍**：

$$1 + \frac{R_f}{R_g} \geq 3 \quad\Longrightarrow\quad R_f \geq 2R_g$$

倍数小于 3，每转一圈信号都缩小，振荡慢慢消失；大于 3，每转一圈都变大，直到碰到运放的输出极限被削平。

## 三、仿真：从噪声"荡"起来

下面的程序用最朴素的方法求解电路：每 0.2 µs 算一步电容的充放电（这正是 [01 元件速成 · 直觉篇](../01-components-basics/page1.md) 里"电流 = 电容 × 电压变化快慢"的关系）。同相端一开始有 10 mV 的扰动，模拟上电时的噪声。比较三种放大器：

1. $R_f$ = 19 kΩ，倍数 2.9；
2. $R_f$ = 22 kΩ，倍数 3.2，输出超过 ±4 V 就被削平（假设运放输出最大 ±4 V）；
3. **二极管稳幅**： $R_f$ 由 12 kΩ 和"10 kΩ 并一对反向并联二极管"串联组成。小信号时二极管不导通，倍数也是 3.2；信号大了二极管导通，把 10 kΩ 短路掉一部分，倍数自动降回 3 附近。程序里用 $0.6 \tanh(\cdot)$ 近似"二极管两端最多约 0.6 V"。

二极管稳幅的接法见图 24-p2-6。

![文氏桥的反馈电阻换成 12 千欧电阻串联一个并联组：10 千欧电阻与两只方向相反的二极管 D1、D2 并联](img/24_p2_6_diode_agc.png)

*图 24-p2-6　二极管稳幅的文氏桥：R_f 由 12 kΩ 和「10 kΩ 并一对反向并联二极管」串联组成*

图 24-p2-6 中朱红色部分取代了图 24-p2-1 的 22 kΩ。 $D_1$ 、 $D_2$ 方向相反，正半周和负半周各由一只导通，所以对正负两个方向的削减是对称的。

代码与仓库里的 code/24_sim.py 内容一致，存成文件后**在仓库根目录运行**（开头两行会找到 code/figs 里的画图样式）。

```python
import sys, pathlib
sys.path.insert(0, str(pathlib.Path("code/figs").resolve()))  # 在仓库根目录运行
# 24 振荡器最小仿真：文氏桥正弦振荡器的起振过程，比较「增益不足」「增益过大」「有稳幅」三种情况。
import numpy as np                                 # 数组运算
import matplotlib.pyplot as plt                    # 画图
import figstyle as fs                              # 全书统一的颜色、轴标签、保存函数

R, C = 10e3, 10e-9                                 # 文氏桥：两个 R = 10 kΩ，两个 C = 10 nF
f0 = 1 / (2 * np.pi * R * C)                       # 振荡频率 f0 = 1/(2πRC) ≈ 1.59 kHz
Rg, VMAX = 10e3, 4.0                               # 反相端接地电阻 10 kΩ；假设运放输出最大 ±4 V
dt, T = 0.2e-6, 20e-3                              # 每 0.2 µs 算一步，共算 20 ms
t = np.arange(0, T, dt)                            # 时间轴

def vo_fixed(vx, Rf):                              # 普通同相放大：Vo = (1 + Rf/Rg)·V+，超出 ±4 V 就被削平
    return np.clip((1 + Rf / Rg) * vx, -VMAX, VMAX)

def vo_diode(vx):                                  # 有稳幅：Rf = 12 kΩ + (10 kΩ 并一对反向并联二极管)
    i = vx / Rg                                    # 虚短：反相端电压 = V+，流过 Rg 和 Rf 的电流 = V+/Rg
    vb = 0.6 * np.tanh(i * 10e3 / 0.6)             # 10 kΩ 两端电压：小时按欧姆定律，大时被二极管限在约 0.6 V（近似模型）
    return np.clip(vx + i * 12e3 + vb, -VMAX, VMAX)  # 输出 = 反相端电压 + 两段反馈电阻上的压降

def run(amp):                                      # 给定放大规律，数值求解文氏桥电路
    vc, vx = 0.0, 0.01                             # 串联电容电压 0；同相端有 10 mV 的初始扰动（模拟噪声）
    out = np.empty_like(t)
    for k in range(len(t)):
        vo = amp(vx)                               # 运放输出
        i = (vo - vx - vc) / R                     # 串联支路（R 与 C 串联）里的电流
        vc += i / C * dt                           # 串联电容充电
        vx += (i - vx / R) / C * dt                # 并联支路：电流一部分走 R 到地，其余给并联 C 充电
        out[k] = vo
    return out

cases = [("增益 2.9（Rf = 19 kΩ）：不起振", "增益 2.9（$R_f$ = 19 kΩ）：不起振",  # 终端用纯文本，图上用公式字体
          run(lambda v: vo_fixed(v, 19e3)), "bad"),
         ("增益 3.2（Rf = 22 kΩ）：起振后削顶", "增益 3.2（$R_f$ = 22 kΩ）：起振后削顶",
          run(lambda v: vo_fixed(v, 22e3)), "third"),
         ("二极管稳幅（小信号增益同为 3.2）", "二极管稳幅（小信号增益同为 3.2）", run(vo_diode), "vout")]
late = t > 15e-3                                   # 取最后 5 ms 看稳定后的幅度
for name, _, y, _ in cases:
    print(f"{name}：最后 5 ms 峰值 {np.max(np.abs(y[late])):.2f} V")
assert np.max(np.abs(cases[0][2][late])) < 0.01    # 增益不足：振荡衰减到几乎为零
assert np.max(np.abs(cases[1][2][late])) > 3.99    # 增益过大：顶到 ±4 V 被削平
assert 1.0 < np.max(np.abs(cases[2][2][late])) < 3.9  # 稳幅：幅度停在削顶以下
mid = (t > 10e-3) & (t < 15e-3)                    # 再取 10～15 ms 比较，确认幅度已经稳定
assert abs(np.max(np.abs(cases[2][2][mid])) - np.max(np.abs(cases[2][2][late]))) < 0.05
n = np.sum(np.diff(np.sign(cases[2][2][late])) > 0)   # 数最后 5 ms 里有几次向上过零
print(f"振荡频率 理论 {f0:.0f} Hz，仿真约 {n / 5e-3:.0f} Hz")
assert abs(n / 5e-3 - f0) < 0.1 * f0

fig, axs = plt.subplots(3, 1, figsize=fs.SIZE["tall"], sharex=True)  # 三行，共用时间轴
for ax, (_, title, y, ls) in zip(axs, cases):
    ax.plot(t * 1e3, y, **{**fs.LS[ls], "lw": 0.9})  # 输出电压波形
    ax.set_title(title, fontsize=9, loc="left")     # 每行标题说明是哪种情况
    ax.set_ylim(-5, 5); ax.set_ylabel("$V_o$ / V")
    fs.ref_h(ax, VMAX, "±4 V（输出极限）", x=0.99)   # 灰色点线：输出极限
    fs.ref_h(ax, -VMAX)
fs.axlabels(axs[2], "时间", "ms")                   # 横轴标签
fs.save(fig, "24", "24_p2_3_wien_startup.png")     # 保存到 24-oscillator/img/
```

运行后打印：倍数 2.9 时最后 5 ms 的峰值为 0.00 V；倍数 3.2 时峰值顶在 4.00 V；二极管稳幅时峰值稳定在 1.85 V，频率理论值 1592 Hz，仿真约 1600 Hz（按 5 ms 内的过零次数粗算）。波形见 图 24-p2-3。

![三行波形：第一行朱红色几乎是一条零线；第二行红紫色点划线振幅逐渐增大后顶到正负 4 伏被削平；第三行橙色振幅增大到约 1.85 伏后稳定](img/24_p2_3_wien_startup.png)

*图 24-p2-3　文氏桥起振过程：增益不足、增益过大、二极管稳幅*

图 24-p2-3 第一行（朱红色带 ×）：倍数 2.9，最初的 10 mV 扰动一圈圈变小，电路"不起振"。第二行（红紫色点划线）：倍数 3.2，大约 4 ms 就长到灰色点线 ±4 V 并被削平，波形顶部是平的。第三行（橙色）：起振一样快，但长到约 1.85 V 后就不再长了，顶部仍是圆的。**稳幅的意思是：起振时倍数略大于 3，振起来后倍数自动回到 3**。

用数字看看二极管怎样"自动调倍数"：小信号时二极管不导通， $R_f$ = 12 + 10 = 22 kΩ，倍数 3.2，大于 3，振幅长大；若二极管完全导通，10 kΩ 被短路， $R_f$ 只剩 12 kΩ，倍数 2.2，小于 3，振幅缩小。实际振幅停在两者之间的某处，让一个周期"平均下来"的倍数正好是 3。仿真里这个位置是峰值约 1.85 V。这个幅度没有简单公式可以估算，只能靠仿真或实验得到，它和二极管的特性有关。程序里的二极管是用 0.6·tanh 近似的；用真实的 1N4148 做实验，二极管在约 0.5 V 就开始导通，峰值会更小一些，约 1.6～1.7 V（LM358B + 1N4148 仿真为 1.65 V），具体数值还和二极管的型号、温度有关。

## 五、弛张振荡器的周期

**意思**：电容从下门限充到上门限所用的时间，加上从上门限放到下门限的时间，就是一个周期。

**一步一步推**。

1. **RC 充电的规律（01）**。电容经电阻朝某个"目标电压"充电时，它离目标的**差距**每过一段时间按同样的比例缩小：

$$V_{\text{目标}} - V_C(t) = \left(V_{\text{目标}} - V_{\text{起点}}\right) e^{-t/(RC)}$$

这里 $e \approx 2.718$ 是自然常数， $t$ 是从起点开始计的时间。

2. **代入充电半周**。输出为 5 V，目标是 5 V；起点是下门限 1.67 V，差距 3.33 V；终点是上门限 3.33 V，差距 1.67 V。差距正好缩小到**一半**，所以

$$e^{-t/(RC)} = \frac{1}{2} \quad\Longrightarrow\quad t = RC \ln 2 \approx 0.69RC$$

3. **放电半周对称**。输出为 0 V，电容朝 0 V 放电，从 3.33 V 到 1.67 V，差距也是从 3.33 V 缩到 1.67 V，同样用 0.69 $RC$ 。两段相加：

$$T = 2RC\ln 2 \approx 1.39RC$$

注意结果里**没有电源电压**：门限是电源的 1/3 和 2/3，换成 12 V 电源，差距仍是"缩小一半"，周期不变。TI 的 SNOA998A 中的同类电路也把门限设在电源的 1/3 和 2/3，每半周同样是 0.69 $RC$ 。

**代数**： $R$ = 10 kΩ， $C$ = 100 nF， $RC$ = 1 ms， $T \approx 1.39$ ms，频率约 721 Hz，与 [直觉篇](page1.md) 的仿真一致。

## 六、例题

**例 1（完整示范）** 文氏桥用 $R$ = 10 kΩ、 $C$ = 10 nF， $R_g$ = 10 kΩ。频率是多少？ $R_f$ 至少取多大？

第 1 步，意思：频率由 RC 决定；网络在 $f_0$ 处送回 1/3，倍数至少为 3。

第 2 步，代数： $f_0 = 1/(2\pi \times 10\ \text{k}\Omega \times 10\ \text{nF}) \approx 1592$ Hz。

第 3 步，代数： $1 + R_f/R_g \geq 3$ ，即 $R_f \geq 2R_g$ = 20 kΩ。

第 4 步，取值：正好 20 kΩ 时电阻误差一点点就会停振，所以实际取略大的 22 kΩ（倍数 3.2），再加二极管稳幅，防止削顶。

**例 2（填空）** 弛张振荡器用 $R$ = 10 kΩ、 $C$ = 1 µF（三个门限电阻相等），电源 5 V。

第 1 步：门限为 ____ V 和 ____ V。

第 2 步： $RC$ = ____ ms， $T \approx 1.39 \times$ ____ = ____ ms，频率约 ____ Hz。

<details><summary>答案</summary>

第 1 步：1.67 V 和 3.33 V（电源的 1/3 和 2/3）。

第 2 步： $RC$ = 10 ms； $T \approx 1.39 \times 10$ = 13.9 ms；频率约 72 Hz。

</details>

**例 3（变体迁移）** 只有 10 nF 电容，想让文氏桥振在 1 kHz，两个 $R$ 取多大？

<details><summary>答案</summary>

把公式变形： $R = 1/(2\pi f_0 C) = 1/(2\pi \times 1000 \times 10 \times 10^{-9}) \approx 15.9$ kΩ，两个 $R$ 必须相等（两个 $C$ 也相等），否则频率公式和"3 倍"的条件都会变。放大部分不用改。

</details>

## 本页小结

**文氏桥的频率 $f_0 = 1/(2\pi RC)$ ，网络在 $f_0$ 处把信号打成 1/3，所以放大倍数需略大于 3，并靠二极管等稳幅让倍数自动回到 3；弛张振荡器的门限取电源的 1/3 和 2/3 时，每半周差距缩小一半， $T \approx 1.39RC$ ，与电源电压无关；正弦接比较器即可得到同频方波**。

常见标准电路教案（高中电路基础起步）

网页版（手机也能读，公式已渲染）：https://helplesstuxe.github.io/basic-circuits-tutorial/

这是一套面向只有高中物理电路基础的学习者的中文教案，用浅显但严谨的方式讲透 20 种常见标准电路，并扩展讲解 MOS 管开关、继电器驱动、光耦与隔离等常用功能电路；全部内容是 Markdown 加 Python 生成的图片。

题目来源是一张「20种常见标准电路」图（specs/source-20-circuits.jpg），任务说明见 specs/task-spec.md，教学设计见 notes/00-design.md。

怎么读

每个知识点 4 页：page1「直觉篇」讲为什么需要它、它像什么；page2「原理与实现篇」讲推导并附可运行的 Python 仿真；page3「参数与调试篇」讲怎么选元件、出了故障怎么查，最后有练习题；page4「动手实验篇」带你在面包板上用不超过 12 V 的直流把电路搭出来，用万用表逐点测量，并和 SPICE 仿真或计算值对照。建议先读前置知识 01–03，再按下面依赖图的箭头顺序往后读。标 ⚠ 的知识点涉及 220V/380V 市电，只在低压下做仿真和实验；动手之前请先读下面的「动手实验安全须知」。

怎么运行代码

  1. 建虚拟环境，装这几个包（需要 Python 3.10 以上；本仓库在下面的版本上测试过）：

    python3 -m venv circuits-venv                 # 路径随意，下面都用这个名字
circuits-venv/bin/pip install numpy matplotlib scipy schemdraw markdown-it-py
# 测试版本：numpy 2.5.4、matplotlib 3.11.2、scipy 1.18.1、schemdraw 0.23、markdown-it-py 4.2.0

    图中的中文需要系统装有中文字体（本仓库在 Noto Sans CJK SC 下测试；Windows 的微软雅黑、macOS 的苹方也可以）。

  2. 一律在仓库根目录运行。脚本和页面里的代码块都按「当前目录 = 仓库根目录」找 code/figs/figstyle.py 和各节点的 img/；在别的目录运行会报找不到 figstyle。

    cd basic-circuits-tutorial
circuits-venv/bin/python code/07_sim.py                 # 运行一个节点的仿真
circuits-venv/bin/python code/figs/07_figs.py           # 重画这个节点的配图
circuits-venv/bin/python tools/run_blocks.py --scripts  # 运行 code/ 里全部仿真和画图脚本

    页面里的代码块可以单独复制运行：复制成一个 .py 文件，同样在仓库根目录运行。用到 figstyle 的代码块开头都有两行 sys.path.insert(...)，不要删。

  3. fs.save 会覆盖 img/ 里的图。code/ 里的仿真和画图脚本都用 fs.save(fig, "NN", "NN_pX_k_含义.png") 保存图，它把图写回对应节点的 img/ 文件夹（不管你复制到哪里运行，写的都是仓库里那个 img/），页面引用的就是这些文件。改了参数再运行，页面上的图也跟着变。

  4. 想改脚本做实验，先复制一份，例如 cp code/07_sim.py my_07.py，改副本，并把副本里的 fs.save(...) 换成 plt.show() 或 fig.savefig("my_test.png")。否则一运行就会把 img/ 里的正式配图换掉，页面上的数字和图就对不上了；万一改坏了，用 git checkout -- code/ NN-slug/img/ 恢复。

仓库结构：

  • 01-…、02-… 等：每个知识点一个文件夹，内含 page1–4 和 img/。
  • code/：各节点的仿真和画图脚本；code/figs/ 是共用的配色字体模块 figstyle.py 和电路图模块 schem.py。
  • spice/：ngspice 复核电路，spice/NN/ 是各节点的 .cir 网表和 run.py，spice/models/ 是厂商 SPICE 模型。
  • review/：审阅报告；review/spice/ 是 SPICE 复核报告。
  • tools/：检查工具（汉字数、代码块运行、配图、GitHub 公式渲染）和网页发布脚本（tools/publish_clean.sh 在干净的 git worktree 里从已推送的提交发布）。
  • notes/：教学设计与作者指南；specs/：任务说明与原始附图。

动手实验安全须知

page4「动手实验篇」的电路都是按下面几条设计的，自己改电路时也请照做：

  1. **只用 12 V 及以下的直流电。**电池、电池盒或 12 V 以下的成品直流适配器都可以。唯一的例外是 13 桥式整流：它用外壳密封的 9 V 交流输出适配器（或信号发生器）给整流桥供电，变压器装在适配器里，你接触到的只有 9 V 低压。
  2. ±9 V 是两节 9 V 电池串联得到的，中间的连接点当作地（0 V）。注意两根电源轨之间实际相差 18 V，超过了「12 V」这条线：接线时别让正负轨碰在一起，也别把只能承受 12 V 以下的元件（例如 16 V 以下的电解电容）跨接在两轨之间。用到 ±9 V 的是 02、05、08、09、12、14、16、18、20 的 page4。
  3. 电解电容分正负，接反会发热、鼓包甚至炸开；电阻、稳压管、三极管可能烫手，通电时不要用手捏。改线之前先断电。
  4. **标 ⚠ 的市电节点（04、07、11、13、15、23、25、27、28）只做低压替代实验。**这些页面里的 220 V/380 V 电路只能看图、看仿真，不要接 220 V，也不要拆开适配器或插座。23 的市电过零检测、28 的市电一次侧都不做实验。真要安装、改动市电线路，请找持证电工。

# 33 带通与 50 Hz 陷波 · 调研笔记（作者 B）

## 理论
- TI SBOA114《Design Methodology for MFB Filters in ADC Interface Applications》https://www.ti.com/lit/an/sboa114/sboa114.pdf （已打开）：MFB 结构与设计流程。
- TI SBOA228（单电源二阶 MFB 带通电路手册）https://www.ti.com/lit/an/sboa228/sboa228.pdf （已打开）：
  - 1–10 kHz 宽带通，低通部分 R = 10 kΩ ×3、C1 = 3.3 nF、C2 = 750 pF；
  - 高通部分 C = 1 nF ×3、R4 = 75 kΩ、R5 = 336 kΩ；
  - TLV9062 在 5 V 下工作，Vref 1.25 / 2.5 V。
- TI TLV522 数据手册 https://www.ti.com/lit/ds/symlink/tlv522.pdf （已打开）：双 T 陷波手册取 R = 10 MΩ、C = 270 pF 作 60 Hz 的近似（按手册式 F0 = 1/(2πRC) 计算值 58.9 Hz）；50 Hz 用 R = 11.8 MΩ、C = 270 pF（约 49.95 Hz）。
- TI SLYT235《High-speed notch filters》（Bruce Carter）https://www.ti.com/lit/an/slyt235/slyt235.pdf （已打开）：实际陷波深度受元件精度限制；给出不同 Q 的曲线。
- 应用背景：
  - 超声 1–2 MHz 回波，以及 TDC1000 的激励频率范围 31.25 kHz–4 MHz（https://www.ti.com/lit/ds/symlink/tdc1000.pdf ，已打开）；
  - 涡街几十 Hz 到 kHz（横河技术报告，见 32-research）。

## 推导链
1. 带通 = 低通 × 高通；f_0 是中心，BW = f_0/Q 值。
2. MFB 带通（等电容 C）：
   - f_0 = (1/(2πC))·√((R1+R3)/(R1·R2·R3))；
   - Q 值 = π·f_0·R2·C；
   - 中心增益 = −R2/(2R1)。
   - 反解（中心增益大小 A）：R1 = Q值/(2π f_0 C A)，R2 = Q值/(π f_0 C)，R3 = Q值/(2π f_0 C (2Q值² − A))；要求 2Q值² > A。作者对照 SBOA114 的符号改写，并用 calc.py 数值反代验证。
3. 双 T：两条 T 形支路，一条 R-R-2C（中间 C 接地处为 2C），一条 C-C-R/2；在 f_0 = 1/(2πRC) 处相位相反、相消。
4. 运放要求：在 f_0 处开环增益要远大于 2·Q 值²（经验规则，资料中未找到原文，见待核实；用 SPICE 证明）。

## 算例（calc.py 已复核）
- 等电容 MFB：f_0 = 1 kHz、Q 值 = 5、C = 10 nF、中心增益 1 → R2 = 159.2 kΩ、R1 = 79.6 kΩ、R3 = 1.624 kΩ；2Q值² = 50。
- 双 T：33 kΩ、100 nF → 48.2 Hz（R/2 用两只 33 kΩ 并联，2C 用两只 100 nF 并联）。

## 常见错误
- 【已按理论勘误改】R2 或 R3 偏 1% 时 f_0 偏约 0.5%（电阻误差的一半），与 Q值 几乎无关（code/33_sim.py）；Q值 越高带宽越窄，同样的偏移占带宽的比例越大（Q值 = 20 时约 10%）。R1 偏 1% 让中心增益变 1%。
- 【已按理论勘误改】双 T 失配时深度主要受坑底频率漂移影响；SLYT235 只说实际元件「最好也只能期望 40 到 50 dB」，具体深度以本节 SPICE/Python 为准。
- 运放 GBW 不够，高 Q 带通的峰值偏移。
- 50 Hz 陷波只在 50 Hz 附近有用；在 60 Hz 电网地区要改值（TLV522 给了两组值）。
- 单电源忘了 Vref 偏置（SBOA228 用 1.25/2.5 V）。

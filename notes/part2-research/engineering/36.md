## 1. 真实产品/参考设计怎么做

### 1.1 回差比较器的官方参考设计
- **TI TIDU020A《Comparator with Hysteresis Reference Design》**（已用 curl 下载 PDF）
  - 条件：5 V 供电，输入 0–5 V。
  - 接法：输入接**反相端**；同相端由 Rx/Ry 分压设门限，再用 Rh 从输出正反馈回来。
  - 取值：Rx = Ry = 100 kΩ，Rh = 576 kΩ（计算值 575 kΩ，取最近的标准值）。
  - 结果：目标门限 V_L 2.3 V、V_H 2.7 V。TLV3202 实测 2.32/2.74 V，回差 0.42 V（Table 1）。
  - 文中提醒：推导是按推挽输出做的，开集电极输出要加上拉 R_p，它会和反馈网络构成分压（§"open-collector output stage requires a pull-up resistor"），所以 Rh 要远大于 R_p。
  - **意义**：这种「信号进反相端」的接法里，信号源只看到比较器的高阻输入，源阻抗不改变门限。第一部分用的同相接法没有这个优点（见 §2 #3）。
- **TI SNOA997《Inverting Comparator With Hysteresis Circuit》**（Analog Engineer's Circuit，已用 curl 下载 PDF）：讲同类反相回差电路的设计步骤，从 V_H、V_L 和电源反推电阻。

### 1.2 比较器 LM393（TI SLCS005AH，§5.8 Electrical Characteristics for LM193/LM293/LM393，V_CC = 5 V）
- 输入失调：2 mV 典型、5 mV 最大（25 °C）。
- I_IB：−25 nA 典型、−250 nA 最大（25 °C），全温 −400 nA。
- 共模范围：0 到 V_CC−1.5 V（25 °C），全温 0 到 V_CC−2 V。脚注说明：只要有一个输入在共模范围内，另一个输入可以到 V_CC。
- 输出：V_OL 在 I_OL = 4 mA 时 150 典型、400 mV 最大；I_OL 6 mA 最小（V_OL = 1.5 V 时）。
- 速度：响应时间典型 1.3 µs（器件对比表）。
- 电源电流：V_CC = 5 V 时 0.8 mA 典型、1 mA 最大。

### 1.3 工业脉冲式流量计
- **Omega《Turbine & Paddle Wheel Flowmeter Reference》**：
  - 涡轮转动时在磁电拾取线圈（magnetic pickup coil）里感应出脉冲。
  - K = 60f/Q，其中 f 为脉冲/秒，K 为脉冲/加仑，Q 单位是 GPM；也写成 f = KQ/60。
  - K 系数只在线性范围内近似为常数。
- 拾取线圈的信号幅度随流速变化，低流量时只有几十 mV。所以真实变送器的前端都是「放大 → 带回差的比较器 → 计数器或 MCU 的捕获口」。
- 本节 page4 用 555 方波经 RC 整形来模拟这种信号。

### 1.4 MCU 侧：ATmega328P（DS40002061B）
- **ICP1 = PB0 = Arduino D8**（引脚表；§ "ICP1, Input Capture Pin: The PB0 pin can act as an Input Capture Pin for Timer/Counter1"）。
- 输入捕获单元带 **Noise Canceler**，但它只是让延迟增加 4 个系统时钟、滤掉更短的毛刺（250 ns 量级）。**它不能代替回差**：过零附近的抖动是 µs 到 ms 量级，照样会被计数。
- I/O 门限（Table 30-1，V_CC 2.4–5.5 V）：V_IL 最大 0.3 V_CC = 1.5 V，V_IH 最小 0.6 V_CC = 3.0 V。

### 1.5 布局要点
- 比较器的 V_CC 就近接 0.1 µF；两只 555 各自的 V_CC 也就近接 0.1 µF，pin 5 各接 10 nF 到地。
- 噪声 555 和信号线分开走线：噪声只应从设计好的 R_n + C_n 注入。
- 上拉电阻接 Arduino 的 5 V。即使比较器接 9 V，**上拉也只能接 5 V**，否则 D8/D2 会被灌进 9 V。开集电极输出允许这样接。

### 需要作者改正的要点
1. **不要把第一部分的同相施密特直接接到 RC 整形网络上**：源阻抗会改变门限（10 kΩ 源阻抗时门限变成 3.00/2.01 V）。改用反相接法：信号进 IN−，同相端用 10 k/10 k 分压，R2 = 47 k 正反馈，上拉 2.2 k → 门限 2.73/2.26 V。可以引用 TIDU020 作为官方同类设计。
2. **噪声要经电容耦合注入**（R_n + 100 nF），耦合电容后串 10 kΩ，避免 RC 网络的电容把噪声短路掉。按已运行的仿真，R_n = 100 k 为「施密特能救回来」，R_n = 47 k 为「噪声超过回差，施密特也失败」。
3. **倒数计数改用 Timer1 预分频 /8**（50 ppm@100 Hz），或者在正文写明 /1 时要计溢出；6.25 ppm 这个数字只在处理了溢出时才成立。
4. Noise Canceler 不能代替回差，正文不要暗示「MCU 里有滤波就不用施密特」。
5. 单门限的计数用中断数出来只是下限，因为 ISR 跟不上 µs 级的抖动。
6. 上拉一律接 5 V，不能接 9 V。
7. 补齐 555 的电阻电容取值、引脚图和一句话原理（§10），并加上万用表 Hz 档和直流档的验证步骤。

### Arduino 输入捕获草图要点（D8，Timer1 /8）
```cpp
volatile uint16_t last=0, period=0; volatile bool fresh=false;
ISR(TIMER1_CAPT_vect){ uint16_t now=ICR1; period=now-last; last=now; fresh=true; }
void setup(){ Serial.begin(115200); pinMode(8,INPUT);
  TCCR1A=0; TCCR1B=(1<<ICNC1)|(1<<ICES1)|(1<<CS11);   // 噪声消除器 + 上升沿 + /8 (0.5 us)
  TIMSK1=(1<<ICIE1); }
void loop(){ if(fresh){ noInterrupts(); uint16_t p=period; fresh=false; interrupts();
  float f=2e6/p; Serial.print(f,3); Serial.print(" Hz  Q="); Serial.print(f*60/100.0,2); Serial.println(" GPM (K=100/gal)"); delay(200);} }
```

print("== 1) 门限计算 ==")
def par(*rs): return 1/sum(1/r for r in rs)
# 第一部分 同相施密特: Vin -R1- (+) -R2- out(上拉 Rp 到 5V); (-) 接 2.5 V
def noninv(R1,R2,Rp,Vref=2.5,Rs=0):
    R1=R1+Rs
    # 输出低(0 V): 上翻门限 Vin 使 V+ = Vref: (Vin-Vref)/R1 = Vref/R2
    VH=Vref+Vref*R1/R2
    # 输出高: 输出经 Rp 到 5 V -> 等效 5 V 串 (R2+Rp)
    VL=Vref-(5-Vref)*R1/(R2+Rp)
    return VH,VL
for Rs in [0,10e3,50e3]:
    VH,VL=noninv(10e3,100e3,2.2e3,Rs=Rs)
    print(f"第一部分同相接法 R1=10k R2=100k Rp=2.2k 源阻抗 {Rs/1e3:4.0f}k: 上门限 {VH:.3f} V 下门限 {VL:.3f} V 回差 {VH-VL:.3f} V")
def inv(Ra,Rb,R2,Rp,V=5.0):
    Rth=par(Ra,Rb); Vth=V*Rb/(Ra+Rb)

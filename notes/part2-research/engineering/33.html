33 带通与 50 Hz 陷波 —— 工程实战调研（工程实战派）

核对对象：/workspace/basic-circuits-tutorial/33-bandpass-notch/page4.md（已存在草稿：LM358 + 9 V 电池；A 区 MFB 带通 R1 82 kΩ / R2 160 kΩ / R3 1.6 kΩ / C 10 nF，VG = 4.5 V 虚地；B 区无源双 T 33 kΩ / 100 nF；手机信号发生器 + 万用表交流挡比值法）。依据 PART2_BRIEF §10（单 9–12 V；MFB "A_OL ≫ 2Q²" 用仿真展示、不引用文献）。

1. 真实产品/参考设计怎么做

  • TI SLOA093《Filter Design in Thirty Seconds》（Bruce Carter, 2001）：
    • §4 窄带带通用"modified Deliyannis"（即 MFB）结构，给出 ± 电源（Fig.11）和 单电源版（Fig.12，同相端接 +Supply/2，输入输出加隔直电容 Cin = Cout = 100–1000 × C1）。
    • 设计说明（p.13）："The Q is set at 10, which also locks the gain at 10 … A higher Q was not selected, because the op amp gain bandwidth product can be easily reached … At least 40 dB of headroom should be allowed above the center frequency peak. The op amp slew rate should also be sufficient…"
    • §6 陷波用 Fliege 结构（Fig.15/16，两只运放，R1 = R2 = 2·Q·R3，增益固定 1），并提醒单电源时下面那只运放的共模范围是唯一风险。
  • TI FilterPro 用户指南 SBFA001C：§3.2 "The MFB topology (sometimes called Infinite Gain or Rauch) is often preferred due to assured low sensitivity to component variations"——这就是工程上用 MFB 做窄带带通的原因。
  • TI UAF42 通用有源滤波器（SBFS002B）：一片集成状态变量滤波器，同时给出 LP/HP/BP 输出，LP+HP 求和得到陷波（数据手册式 3、式 4：带阻传递函数 A_BR(s²+ω_n²)/(s²+sω_n/Q+ω_n²)）；内部运放 GBW 4 MHz（G=+1，电气特性表）。工业上要求稳定、可调的 50/60 Hz 陷波时常用这类状态变量/Fliege 有源结构，而不是无源双 T（双 T 的 Q 固定为 1/4、对 6 只元件匹配敏感，见下方 Monte Carlo）。
  • 布局/元件要点（来自上述文档的设计流程 + 本节计算）：C 用 C0G/NP0 瓷片或薄膜（温漂/电压系数小）；双 T 电容最好用电容挡挑配；高阻节点走线短、远离市电线。

2. page4 可行性逐点核对

# 检查项 结论 依据 / 说明
1 电源 9 V 电池、单电源 + 虚地 ✔ 符合 §10 LM358 电源 3–30 V（表 5.7 所在规格）；V_CM 0 到 V+−1.5 V = 7.5 V，VG 4.5 V 在范围内；输出 4.5 V ± 0.41 Vpk 远离两轨。
2 虚地（RA/RB 10 kΩ + 10 µF + LM358 B 跟随） ✔ 节点 12 做法；带通只从 VG 吸收 µA 级交流电流。
3 LM358 GBW 对 Q = 5 的 MFB 是否够 ✔（有轻微偏移） LM358 GBW 0.7 MHz typ（表 5.7）。1 kHz 处开环增益 ≈ 697，而 MFB 中心频率处所需的环路增益基准 2Q² ≈ 51，余量只有 22.7 dB（低于 SLOA093 对其 Q=10/增益 10 设计建议的 "≥40 dB headroom"）。但用单极点模型精确解节点方程：峰值频率 1004.4 → 997.2 Hz，Q 5.05 → 5.09，峰值增益不变（0.9755）。对万用表实验可以忽略；TL072（3 MHz）只偏到 1002.7 Hz。按 §10，"A_OL ≫ 2Q²" 用这段仿真结果展示，不引用文献。
4 压摆率 ✔ 输出 0.292 Vrms = 0.413 Vpk @1 kHz 需 2.59 mV/µs；LM358 0.3 V/µs（表 5.7），差两个数量级以上。
5 手机地接 VG ✔，前提是手机不充电 草稿已写明。手机靠电池时是浮地，接 VG 没问题。
6 万用表交流挡 1 kHz 读小 ✔ 比值法可行 同频率下先读输入再读输出，频响误差相消；前提是表在该量程内线性。建议在测量表 ④–⑦ 每个频率都重读输入（草稿已写）。
7 B 区坑底读数会被 50 Hz 市电拾取干扰 ⚠️ 需补充 双 T 在坑底附近的输出阻抗约 23 kΩ（Python）。假设导线/人体对 220 V 市电的杂散电容只有 1 pF（示意量级，非实测），注入约 69 nA → 1.6 mV，与坑底读数（48 Hz 约 0.7 mV、50 Hz 约 5.4 mV）同量级。而且手机信号（48–52 Hz）和市电 50 Hz 频率很接近，两者会"拍"，万用表读数会以 |f−50| Hz 的节奏慢慢摆动。对策：表笔线短而且绞在一起；手离开电路；先把手机暂停，读一次"本底"，坑底读数要明显大于本底才算数。
8 万用表 200 mV 交流挡本底 ⚠️ 很多 3½ 位表在表笔短路时交流 200 mV 挡也会显示几个字（具体看自己表的说明书，[待核实]——没有统一数据手册来源）。坑底 < 1 mV 的读数要先减去短路本底。
9 双 T 元件匹配 ✔ 草稿已提示挑电容 Monte Carlo（电阻 1%）：电容 5% 未挑时坑底频率 5–95% 分布为 47.0–49.5 Hz，坑深中位 0.77 mV（输入 300 mV 时）；电容挑到 1% 时为 47.9–48.6 Hz、0.22 mV。按 1 Hz 步进时标称元件最低读数在 48 Hz（0.71 mV），与草稿一致。
10 坑底是 48.2 Hz 而不是 50 Hz 可选改进 若想让"50 Hz 陷波"名副其实：每只 33 kΩ 并 1 MΩ → 31.95 kΩ → 49.82 Hz；R/2 支路同理（两只 31.95 kΩ 并联）。草稿保留 48.2 Hz 也可以，但正文要解释 50 Hz 处只剩 −35 dB（0.018）。
11 没有手机时的替代信号源 建议补一句 Arduino tone() 只能输出方波，最低 31 Hz（Arduino 语言参考 tone.adoc："It is not possible to generate tones lower than 31Hz"），且会占用 D3/D11 的 PWM。方波测带通可以（谐波被滤掉，草稿"方波"小检查即此）；但不能用来测双 T 坑底：3 次谐波（约 145 Hz）幅度是基波的 1/3，双 T 在 3 倍坑底频率处 |H| = 8/√208 ≈ 0.55（按 page4 代码中的公式），输出会被谐波主导。5 V 方波还要经隔直电容 + 分压才能接到以 VG 为零点的电路。
12 双 T 直接由手机驱动 ✔ 双 T 在 1 kHz 时输入阻抗约千欧量级（100 nF 的容抗 1.59 kΩ），耳机口本来驱动 16–32 Ω 耳机，负载无压力。

3. Python 计算（已运行）

import numpy as np
# ===== 1. MFB 带通：理想 vs 有限 GBW 运放（单极点模型） =====
R1, R2, R3, C = 82e3, 160e3, 1.6e3, 10e-9
def mfb(f, gbw=None):
    s = 2j*np.pi*f
    A = np.inf if gbw is None else gbw*2*np.pi/s          # A(s) ≈ GBW/s（远高于主极点）
    Y1, Y2, Y3, Yc = 1/R1, 1/R2, 1/R3, s*C
    # 节点 A：(Va-Vin)Y1 + Va Y3 + (Va-Vn)Yc + (Va-Vo)Yc = 0
    # 节点 N：(Vn-Va)Yc + (Vn-Vo)Y2 = 0 ，运放：Vo = -A*Vn
    # 未知量 Va, Vn, Vo；Vin = 1
    M = np.array([[Y1+Y3+2*Yc, -Yc, -Yc],
                  [-Yc, Yc+Y2, -Y2],
                  [0, (A if np.isfinite(A) else 1.0), (1.0 if np.isfinite(A) else 0.0)]], dtype=complex)
    b = np.array([Y1, 0, 0], dtype=complex)
    if not np.isfinite(A):   # 理想运放：Vn = 0
        M[2] = [0, 1, 0]
    return np.linalg.solve(M, b)[2]
f = np.logspace(np.log10(300), np.log10(3000), 20001)
for name, gbw in (("ideal", None), ("LM358 0.7MHz", 0.7e6), ("TL072 3MHz", 3e6)):
    H = np.array([abs(mfb(x, gbw)) for x in f])
    i = H.argmax(); half = f[H >= H[i]/np.sqrt(2)]
    print(f"{name:13s}: f_peak = {f[i]:7.1f} Hz, |H|peak = {H[i]:.4f}, BW = {half[-1]-half[0]:6.1f} Hz, Q = {f[i]/(half[-1]-half[0]):.2f}")
# 运放开环增益 / 中心频率处所需"噪声增益"
f0 = 1/(2*np.pi*C)*np.sqrt((R1+R3)/(R1*R2*R3)); Q = np.pi*f0*R2*C
print(f"f0 = {f0:.1f} Hz, Q = {Q:.2f}, 2Q^2 = {2*Q*Q:.1f}, LM358 |A_OL|@f0 = {0.7e6/f0:.0f} ({20*np.log10(0.7e6/f0/(2*Q*Q)):.1f} dB headroom)")
# 压摆率需求
vpk = 0.292*np.sqrt(2)
print(f"slew needed at 1 kHz, {vpk:.3f} Vpk: {2*np.pi*1e3*vpk/1e6*1e3:.2f} mV/us  (LM358 0.3 V/us)")

# ===== 2. 双 T：输出阻抗（易拾取 50 Hz）与失配下的坑深 =====
def twint(f, R, Cc, Ra=None, Rb=None, Ca=None, Cb=None, C2=None, Rh=None, Zload=np.inf, out_imp=False):
    Ra = Ra or R; Rb = Rb or R; Ca = Ca or Cc; Cb = Cb or Cc; C2 = C2 or 2*Cc; Rh = Rh or R/2
    s = 2j*np.pi*f
    # 节点 M（电阻T中点）、N（电容T中点）、O（输出）；Vin=1
    G = np.array([[1/Ra+1/Rb+s*C2, 0, -1/Rb],
                  [0, s*Ca+s*Cb+1/Rh, -s*Cb],
                  [-1/Rb, -s*Cb, 1/Rb+s*Cb+(0 if np.isinf(Zload) else 1/Zload)]], dtype=complex)
    if out_imp:   # 输入短路，向输出注入 1 A，求 Zout
        return np.linalg.solve(G, np.array([0, 0, 1], dtype=complex))[2]
    return np.linalg.solve(G, np.array([1/Ra, s*Ca, 0], dtype=complex))[2]
R, Cc = 33e3, 100e-9
fn = 1/(2*np.pi*R*Cc)
print(f"twin-T null = {fn:.2f} Hz; |H(50)| = {abs(twint(50,R,Cc)):.4f}; |H(1k)| = {abs(twint(1000,R,Cc)):.4f}")
for fz in (fn, 50):
    print(f"  |Zout| at {fz:.1f} Hz = {abs(twint(fz,R,Cc,out_imp=True))/1e3:.1f} kOhm")
Rp = 1/(1/33e3+1/1e6)
print(f"33k||1M = {Rp/1e3:.2f} k -> null = {1/(2*np.pi*Rp*Cc):.2f} Hz")
# Monte Carlo：电阻 1%，电容 5%（未挑）vs 电容挑到 1%
rng = np.random.default_rng(0)
ff = np.linspace(40, 60, 801)
for ctol in (0.05, 0.01):
    depth = []; fmin = []
    for _ in range(400):
        r = R*(1+rng.uniform(-.01,.01,4)); c = Cc*(1+rng.uniform(-ctol,ctol,4))
        H = np.abs([twint(x,R,Cc,Ra=r[0],Rb=r[1],Rh=1/(1/r[2]+1/r[3]),Ca=c[0],Cb=c[1],C2=c[2]+c[3]) for x in ff])
        depth.append(H.min()); fmin.append(ff[H.argmin()])
    depth = np.array(depth)
    print(f"  C tol {ctol*100:.0f}%: null depth median {np.median(depth)*300:.2f} mV (of 300 mV), 90th pct {np.percentile(depth,90)*300:.2f} mV; null f 5-95%: {np.percentile(fmin,5):.1f}-{np.percentile(fmin,95):.1f} Hz")
# ===== 3. 工频拾取估算（假设：导线/人体对 220 V 市电杂散电容 1 pF，仅示意量级） =====
Cs, Vm = 1e-12, 220
I = 2*np.pi*50*Cs*Vm
print(f"stray 1 pF to 220 V mains: I = {I*1e9:.0f} nA -> on Zout 23 kOhm: {I*abs(twint(50,R,Cc,out_imp=True))*1e3:.2f} mV")
# 每 1 Hz 读一次时实际能看到的最低读数（标称元件）
for x in range(45, 53):
    print(f"  {x} Hz: {abs(twint(x,R,Cc))*300:.2f} mV", end="")
print()

## 这一页要解决的问题

[08 同相放大 · 直觉篇](page1.md) 用"撬棍"说明了同相放大的倍数是 1 + $R_f/R_1$ 。这一页要回答三个更具体的问题：这个公式怎么用虚短、虚断一步步推出来？"输入端几乎不取电流"到底能带来多大好处？倍数能不能做到 1 以下？负反馈拿走了运放的大部分倍数，换回来了什么（「反馈深度」）？最后用三道例题练习设计，其中第三道把"分压"和"同相放大"组合起来。

## 一、用虚短和虚断推导

先看 图 08-p2-1，图上标出了推导要用的两条口诀。

![同相放大电路，反相端标着 V 减约等于 V i（虚短），输入线上标着电流约为 0（虚断）](img/08_p2_1_analysis.png)

*图 08-p2-1　推导用的同相放大电路：反相端电压等于输入，输入端不取电流*

图 08-p2-1 中，反相端旁边写着"等于输入电压（虚短）"，输入线下方写着"电流约为 0（虚断）"。推导分三步。

**第一步：虚短，反相端电压等于输入**。有负反馈且输出没有饱和时，两个输入端电压几乎相等。同相端就是 $V_i$ ，所以反相端电压 $V_-$ （反相输入端对地的电压）

$$V_- \approx V_i$$

**第二步：虚断，接地电阻和反馈电阻里是同一个电流**。反相端不取电流，所以 $R_f$ 和 $R_1$ 串联，组成从输出到地的分压器。按 01 的分压公式，分压点电压等于输出乘以"下臂电阻占总电阻的比例"：

$$V_- = \frac{R_1}{R_1 + R_f}\thinspace V_o$$

代数： $R_1$ =10 kΩ、 $R_f$ =20 kΩ，比例是 10/30 = 1/3，反相端电压是输出的三分之一。

**第三步：两式联立**。反相端既等于 $V_i$ ，又等于输出的三分之一，所以输出就是输入的 3 倍。一般地

$$V_o = \frac{R_1 + R_f}{R_1}\thinspace V_i = \left(1 + \frac{R_f}{R_1}\right) V_i$$

代数：输入 0.5 V，输出 3 × 0.5 = 1.5 V，与 [08 同相放大 · 直觉篇](page1.md) 一致。所以放大倍数

$$A_v = 1 + \frac{R_f}{R_1}$$

这个式子告诉我们：**运放调整输出，直到分压回来的电压正好等于输入**。这就是负反馈的意思。

**输入电阻**。信号直接接在同相端，而同相端几乎不取电流，所以从信号源看进去的电阻极大，理想情况下可以看成无穷大。LM358B 数据手册给出的差分输入阻抗是 10 MΩ（"阻抗"可以先当成对交流信号的电阻来理解；"差分输入阻抗"就是两个输入端之间的电阻），接成负反馈以后，信号源实际看到的电阻比这个值还要大。

## 二、仿真：信号源内阻大时谁更靠谱

"输入电阻极大"有什么用？下面的仿真让信号源内阻 $R_s$ （信号源内部串联的等效电阻）从 100 Ω 增大到 1 MΩ，用同一对电阻（10 kΩ、20 kΩ）分别搭反相和同相放大，看实际倍数。反相放大的倍数会变成 $R_f/(R_s + R_1)$ （[05 反相放大 · 参数与调试篇](../05-inverting-amp/page3.md) 推过）；同相放大的输入端不取电流，内阻上没有压降，倍数不变。代码与仓库里的 code/08_sim.py 内容一致，存成文件后**在仓库根目录运行**（开头两行会找到 code/figs 里的画图样式，中文标签也靠它显示）。

```python
import sys, pathlib
sys.path.insert(0, str(pathlib.Path("code/figs").resolve()))  # 在仓库根目录运行
# 08 同相放大最小仿真：信号源内阻 R_s 从 100 Ω 增大到 1 MΩ 时，比较反相放大和同相放大的实际倍数。
import numpy as np                                 # 数组运算
import matplotlib.pyplot as plt                    # 画图
import figstyle as fs                              # 全书统一的颜色、轴标签、保存函数

R1, Rf = 10e3, 20e3                                # 两种电路都用 R1 = 10 kΩ、Rf = 20 kΩ
G_inv = Rf / R1                                    # 反相放大：|A_v| = Rf/R1 = 2
G_non = 1 + Rf / R1                                # 同相放大：A_v = 1 + Rf/R1 = 3
Rs = np.logspace(2, 6, 300)                        # 信号源内阻从 100 Ω 扫到 1 MΩ

inv = Rf / (Rs + R1)                               # 反相：内阻和 R1 串联，倍数变成 Rf/(Rs+R1)
non = np.full_like(Rs, G_non)                      # 同相：输入端几乎不取电流，内阻上没有压降，倍数不变

fig, ax = plt.subplots(figsize=fs.SIZE["single"])  # 一张图
ax.axhline(G_inv, **fs.LS["ref"])                  # 灰色点线：反相放大的设计值 2
ax.semilogx(Rs, inv, **fs.LS["third"], label="反相放大（设计 $|A_v|$ = 2）")   # 红紫色点划线
ax.semilogx(Rs, non, **fs.LS["vout"], label="同相放大（设计 $A_v$ = 3）")      # 橙色实线
for r in (1e3, 100e3):                             # 在内阻 1 kΩ 和 100 kΩ 处标数
    g = Rf / (r + R1)                              # 这一点反相放大的实际倍数
    print(f"内阻 {r/1e3:g} kΩ：反相放大实际 |A_v| = {g:.2f}，同相放大仍为 {G_non:.0f}")
    fs.mark(ax, r, g, fmt="{:.2f}", dx=6, dy=-12)  # 黑点 + 数值
fs.mark(ax, 1e3, G_non, fmt="{:.0f}", dx=6, dy=4)  # 同相放大的倍数 3
assert abs(Rf / (100e3 + R1) - 0.18) < 0.01        # 内阻 100 kΩ 时反相只剩约 0.18 倍
assert np.all(non == 3)                            # 同相放大不受内阻影响
fs.axlabels(ax, "信号源内阻 $R_s$", "Ω", "放大倍数", None)                    # 轴标签
ax.set_ylim(0, 3.5); ax.legend(loc="center right", fontsize=8)             # 纵轴范围和图例
```

## 四、最小补充：反馈深度——负反馈拿倍数换来了什么

前面一直说「同相端几乎不取电流」「跟随器输出电阻极小」，但没有说为什么。这一节用一个量把它们串起来。

**三个新名字**。从输出送回反相端的那一部分，占输出的比例叫**反馈系数**，记作 $\beta$ （读作「贝塔」）。本页电路里反相端电压是输出的 $R_1/(R_1+R_f)$ ，所以

$$\beta = \frac{R_1}{R_1 + R_f}$$

代数： $R_1$ =10 kΩ、 $R_f$ =20 kΩ 时 $\beta$ = 1/3；跟随器把输出全部送回去， $\beta$ = 1。信号从运放输入走到输出放大 $A$ 倍（ $A$ 是开环增益，见 [02 运放入门 · 原理与实现篇](../02-opamp-basics/page2.md) ），再经反馈网络乘 $\beta$ 回到输入，绕环一圈的倍数是 $A\beta$ ，叫**环路增益**。在它上面加 1，叫**反馈深度**：

$$\text{反馈深度} = 1 + A\beta$$

代数：LM358B 的典型 $A$ = 14 万（[02 运放入门 · 参数与调试篇](../02-opamp-basics/page3.md) 用的值）， $\beta$ = 1/3 时反馈深度约 46668；跟随器约 14 万，是同一只运放能做到的最深，这就是 [12 电压跟随器 · 参数与调试篇](../12-voltage-follower/page3.md) 说「跟随器反馈最深」的意思。下面四件事，每一件都被这个数乘或除。

**1. 倍数的误差除以反馈深度**。运放不是无穷大倍，两个输入端之间必须留一点点电压差，输出才有东西可放大，所以实际倍数比 $1/\beta$ 小一点，相对误差约为 $1/(A\beta)$ 。代数：1 ÷ (140000 × 1/3) ≈ 0.0021%。[02 运放入门 · 参数与调试篇](../02-opamp-basics/page3.md) 第三节的反相放大误差 (1 + G) ÷ A 其实是同一个式子：反相放大的 $\beta$ 也是 $R_1/(R_1+R_f)$ = 1/(1 + G)。

**2. 输入电阻乘以反馈深度**。看信号从哪条路进来：信号接在同相端，反馈电压接在反相端，运放两个输入端之间的电压是「输入减反馈」，两者在同一个回路里**串联**相减。运放把这个差压到只剩输入的 1/(1 + $A\beta$ )，所以两输入端之间那只 10 MΩ 的差分输入电阻（LM358B 数据手册）上几乎没有电压，也就几乎没有电流。电流小了多少倍，信号源看到的电阻就大了多少倍：

$$R_{in} \approx R_{id}\thinspace(1 + A\beta)$$

这里 $R_{id}$ 是运放本身的差分输入电阻。代数：10 MΩ × 46668 ≈ 4.7 × 10¹¹ Ω。这个数真实芯片达不到：同相端对地还并着一只「共模输入电阻」，[LM358B 数据手册](https://www.ti.com/lit/ds/symlink/lm358b.pdf) 写的是 4 GΩ（4 × 10⁹ Ω），它不被反馈放大；再加上电路板表面的漏电，实际是几 GΩ 的量级。所以本书只说「极大」，不给一个具体数。

对比 [05 反相放大 · 原理与实现篇](../05-inverting-amp/page2.md)：那里信号电流和反馈电流在反相端**同一个节点上汇合**（并联），运放把这个节点钉在 0 V（虚地），从反相端看进去几乎是 0 Ω，信号源看到的只剩 $R_1$ 。口诀：**反馈和输入串联，输入电阻变大；并联，输入电阻变小**。

**3. 输出电阻除以反馈深度**。运放内部本来有输出电阻 $r_o$ ，负载一拉，输出就掉一点。现在反馈网络**取的是输出电压**：输出掉了 ΔV，反相端跟着掉 $\beta$ ΔV，运放把它放大 $A$ 倍，把输出往回推，掉下去的大部分被补了回来：

$$R_{out} \approx \frac{r_o}{1 + A\beta}$$

代数：按 [12 电压跟随器 · 参数与调试篇](../12-voltage-follower/page3.md) 用过的 $r_o$ = 300 Ω 粗算，3 倍同相放大约 6 mΩ，跟随器约 2 mΩ。这里只看量级：300 Ω 是手册在 1 MHz 下给的值，而运放的 $A$ 随频率升高而变小，反馈深度跟着变浅，输出电阻在高频时会重新变大。跟随器带大电容会振铃，根子就在这里。反过来，如果反馈网络**取的是输出电流**（让电流流过一只采样电阻，把电阻上的电压送回去），输出电阻就会变大，输出电流不随负载变，这就是后面 [39 恒流源与线圈励磁驱动](../39-constant-current-excitation/page1.md) 和 [41 4–20 mA 电流环](../41-current-loop-4-20ma/page1.md) 里恒流源的道理。口诀：**取电压，输出电阻变小；取电流，输出电阻变大**。

**4. 失真除以反馈深度**。放大器里面总有不够「直」的地方，比如输出级在零点附近有一段死区。把这些不直的地方看成在输出上额外叠了一个误差：反馈把它和别的误差一视同仁，送回输入，运放再反着推一把，最后留在输出上的只剩原来的 1/(1 + $A\beta$ )。[43 推挽功放 · 原理与实现篇](../43-push-pull-power-amp/page2.md) 会看到一个很直观的例子：两只三极管在零点附近有零点几伏的死区，包进运放的反馈环后，运放每次过零都猛推一下「跳过」死区，负载上的波形几乎没有缺口。同样要注意：频率越高 $A$ 越小，反馈深度越浅，纠正就越弱，所以高频的失真总比低频大。

代价只有一个：倍数从 $A$ （十几万）降到了约 $1/\beta$ （3 倍）。**负反馈就是拿多余的倍数，换精度、换输入输出电阻、换线性**。下面的代码把上面的数算一遍。

```python
# 反馈深度：同一只 LM358B 接成 3 倍同相放大和跟随器，比较误差、输入电阻、输出电阻
A = 140e3                                   # 开环增益典型值 14 万（02 运放入门 · 参数与调试篇）
R_id = 10e6                                 # 差分输入电阻 10 MΩ（LM358B 数据手册）
R_ic = 4e9                                  # 共模输入电阻 4 GΩ（同一手册），不被反馈放大
r_o = 300.0                                 # 开环输出电阻 300 Ω（手册 1 MHz 下的值，只作量级）
for name, beta in (("3 倍同相", 1 / 3), ("跟随器", 1.0)):   # β = R1/(R1+Rf)；跟随器 β = 1
    depth = 1 + A * beta                    # 反馈深度 1 + Aβ
    gain = A / depth                        # 实际倍数 A/(1+Aβ)，比 1/β 略小
    err = (1 / beta - gain) / (1 / beta)    # 相对误差，约等于 1/(Aβ)
    r_in = R_id * depth                     # 只看差分输入电阻时的输入电阻
    r_in_real = 1 / (1 / r_in + 1 / R_ic)   # 再并上共模输入电阻
    r_out = r_o / depth                     # 输出电阻
    print(f"{name}：反馈深度 {depth:.0f}，实际倍数 {gain:.5f}，误差 {err*100:.4f}%，"
          f"输入电阻 {r_in:.2g} Ω（并上 4 GΩ 后 {r_in_real:.2g} Ω），输出电阻 {r_out*1e3:.1f} mΩ")
```

运行后打印：

```text
3 倍同相：反馈深度 46668，实际倍数 2.99994，误差 0.0021%，输入电阻 4.7e+11 Ω（并上 4 GΩ 后 4e+09 Ω），输出电阻 6.4 mΩ
跟随器：反馈深度 140001，实际倍数 0.99999，误差 0.0007%，输入电阻 1.4e+12 Ω（并上 4 GΩ 后 4e+09 Ω），输出电阻 2.1 mΩ
```

## 五、例题

### 例 1（完整示例）：把 0～0.5 V 的传感器信号放大到 0～5 V

**题目**：某传感器输出 0～0.5 V，内阻 20 kΩ，要放大到 0～5 V，±15 V 供电。选电路、选电阻。

**解**：

1. 内阻 20 kΩ 不小，用同相放大，倍数不受内阻影响。
2. 需要 $A_v$ = 5 ÷ 0.5 = 10，即 1 + $R_f/R_1$ = 10，电阻比 9。
3. 取 $R_1$ =10 kΩ，则 $R_f$ =90 kΩ（可用 91 kΩ，倍数 10.1）。
4. 检查：输出最大 5 V，远小于 ±15 V 下约 13.5 V 的上限；带宽约 1.2 MHz ÷ 10 = 120 kHz（同相放大的带宽是 GBW ÷ 倍数，和 05 的 GBW ÷ (1+倍数) 写法不同，原因见 [08 同相放大 · 参数与调试篇](page3.md)），对缓慢变化的传感器绰绰有余。

### 例 2（关键步骤留空）：倍数为 4

**题目**：取 $R_1$ =10 kΩ，要得到 4 倍同相放大， $R_f$ 取多少？输入 0.3 V 时输出多少？

```python
# 不运行
R1 = 10e3
Rf = ____ * R1       # 1 + Rf/R1 = 4，所以 Rf/R1 = ____
V_o = (1 + Rf / R1) * 0.3   # = ____ V
```

### 例 3（变体迁移）：同相加法器

**题目**：要输出 $V_1 + V_2$ （不带负号）。思路：两路信号各经一个 10 kΩ 电阻接到同相端，后面接一个 $R_1$ = $R_f$ =10 kΩ 的 2 倍同相放大。电路如图 08-p2-4 所示，输出是多少？

![同相加法器：V1 和 V2 各经 10 千欧电阻接到同相端，R1 10 千欧从反相端接地，Rf 10 千欧从输出接回反相端](img/08_p2_4_noninv_summer.png)

*图 08-p2-4　同相加法器：两路各经 10 kΩ 接同相端，后接 2 倍同相放大*

**解**：

1. 同相端不取电流，所以图 08-p2-4 里两个 10 kΩ 电阻流的是同一个电流，从 $V_1$ 流向 $V_2$ （或反过来）。同相端在两个相等电阻的正中间，电压就是两路的平均值：同相端电压 = ( $V_1$ + $V_2$ ) ÷ 2。
2. 后面 2 倍同相放大：输出 = 2 × ( $V_1$ + $V_2$ ) ÷ 2 = $V_1$ + $V_2$ 。
3. 代数： $V_1$ =0.5 V、 $V_2$ =0.2 V，同相端 0.35 V，输出 0.7 V，和 [05 反相放大 · 原理与实现篇](../05-inverting-amp/page2.md) 的反相加法器结果大小相同、符号相反。

和反相加法器比，它的缺点是：每一路的权重都受其他路电阻的影响（三路输入时同相端是三路的平均值，倍数就要改成 3），各路之间也会通过这几个电阻互相"串扰"。所以多路混音一般用反相加法器；只有两三路、又不想要负号时才用同相加法器。

## 本页小结

**推导：虚短让反相端等于输入，虚断让两个电阻成为分压器，联立得 $A_v = 1 + R_f/R_1$ 。同相放大的输入电阻极大，信号源内阻再大倍数也不变；倍数最小为 1，电阻比为 0 时就是电压跟随器**。反馈深度 1 + $A\beta$ 决定负反馈的「收益」：倍数误差和失真除以它；反馈与输入串联时输入电阻乘以它，输出取电压时输出电阻除以它。
